# Number Checker 🔢

This project is an in-class console application developed for the **CENG 215** course to practice conditional branching (`if`, `else if`, `else`) and console I/O in C#.

---

## 📋 Description & Logic

The application prompts the user to enter an integer, reads the input from the console, converts it to an integer using `Convert.ToInt32`, and determines whether the number is:
- **Positive:** $\text{number} > 0$
- **Negative:** $\text{number} < 0$
- **Zero:** $\text{number} == 0$

---

## 💻 Sample Runs

### Scenario 1: Positive Number
```text
Enter a number: 42
The number is positive.
```

### Scenario 2: Negative Number
```text
Enter a number: -17
The number is negative.
```

### Scenario 3: Zero
```text
Enter a number: 0
The number is zero.
```
